# Qamar Alumni Connect (72)

Build a complete, professional, and modern School Alumni Portal website for "Qamar E Bani Hashim" school. The entire platform must be in English with a premium, clean, and user-friendly UI/UX. The system requires two main user roles: Alumni and the Website Operator (Super Admin). Please implement the following core features and architecture: 1. Design & Branding: - Clean, trustworthy, and academic yet modern aesthetic. - Use a professional color palette (e.g., Deep Navy Blue, Gold/Yellow accents, and Clean White backgrounds) that reflects a prestigious school identity. - Fully responsive design (Mobile, Tablet, and Desktop friendly). 2. Authentication & User Roles: - Secure Signup and Login system. - Role-based access control: Distinct interfaces and permissions for "Alumni" and "Admin/Operator". 3. Individual Alumni Portals (User Dashboard): - Profile Management: Every alumnus should have their own personal portal/dashboard to update their profile picture, graduation year, contact details, current profession, higher education, and social/LinkedIn links. - Directory Access: A searchable directory to find and connect with other alumni. - Networking Hub: A section to view school news, upcoming alumni meets, and job/mentorship opportunities. 4. Comprehensive Operator Control Panel (Admin Dashboard): - Centralized Control: The Website Operator must have full access to the entire platform. - User Management: A master dashboard to view, approve, edit, suspend, or delete any alumnus account. - Data Overview: High-level analytics showing total registered alumni, breakdown by graduation year, and recent registrations. - Content Management: Ability for the operator to post official school announcements, upcoming events, and gallery updates. 5. Key Pages to Include: - Landing Page: Hero section with school branding, mission statement, latest news ticker, and prominent "Join Alumni Network" and "Login" call-to-actions. - Alumni Directory: Filterable list by graduation year, profession, or city. - About Us & Events Page: To showcase the history of Qamar E Bani Hashim and track upcoming reunions. - Contact Support: A simple form for technical help.
